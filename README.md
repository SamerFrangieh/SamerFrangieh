## What I'm building
 
### ☁️ [Cloud Detection & Response Lab](https://github.com/SamerFrangieh/cloud-detection-lab) — *in progress*
A small, deliberately vulnerable "company" in AWS, built with Terraform, that I attack and then defend.
- CloudTrail (including S3 data events) and VPC Flow Logs, shipped into **Elastic SIEM** through S3 → SQS
- Real attack techniques run with **Stratus Red Team**, mapped to **MITRE ATT&CK** ([attack log](https://github.com/SamerFrangieh/cloud-detection-lab/blob/main/docs/attacks.md))
- Next up: custom detection rules for every technique and an automated Lambda response that disables compromised access keys
### 🛡️ AppSec & DevSecOps Pipeline — *coming soon*
A containerized Flask app on Kubernetes that I threat-model (STRIDE), pentest with Burp Suite, and protect with a GitHub Actions pipeline (Semgrep, OWASP ZAP, Trivy, secrets scanning).
 
### 🧪 Earlier labs
- **SOC Detection Lab** — Wazuh SIEM with custom rules, simulated SSH brute-force and log analysis
- **Malware Analysis Lab** — sandboxed sample analysis and memory forensics with Volatility
